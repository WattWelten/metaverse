# Security Policy

## Supported Versions

Nur der aktive Branch `feat/auto-setup-mvp` und nachfolgende Releases erhalten Security-Fixes.

## Reporting a Vulnerability

Bitte melde Schwachstellen **nicht öffentlich**.

- E-Mail: security@wattwelten.example (anpassen)
- Alternativ: GitHub Security Advisory (privat)

Wir bestätigen innerhalb von 5 Werktagen und veröffentlichen nach Fix ein Security-Advisory mit CVSS-Einschätzung.
