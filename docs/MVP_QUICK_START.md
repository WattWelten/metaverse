# MVP Quick Start – Template-Recherche & Interview

**Version:** 1.0  
**Datum:** 2026-01-11

---

## 🚀 Schnellstart (3 Schritte)

### Schritt 1: Template-Recherche starten

```bash
# Recherche-Script ausführen
node scripts/research-templates.mjs

# Öffne die generierten Search URLs in Browser
# Dokumentiere Kandidaten in docs/TEMPLATE_CANDIDATE_LIST.md
```

**Ziel:** 10-20 Template-Kandidaten finden und dokumentieren

**Zeitaufwand:** 2-4 Stunden

---

### Schritt 2: Designer-Interview durchführen

```bash
# Interview-Protokoll erstellen
node scripts/conduct-template-interview.mjs

# Interview durchführen
# Öffne docs/TEMPLATE_INTERVIEW.md
# Dokumentiere Antworten in docs/TEMPLATE_INTERVIEW_PROTOCOL.md
```

**Ziel:** Präzise Anforderungen für das Template definieren

**Zeitaufwand:** 60-90 Minuten

**Fragen:** 40 strukturierte Fragen in 10 Kategorien

---

### Schritt 3: Design-Briefing finalisieren

```bash
# Basierend auf Interview-Ergebnissen
# Aktualisiere docs/DESIGNER_BRIEFING_DE.md
# Aktualisiere docs/DESIGNER_BRIEFING_EN.md
```

**Ziel:** Finalisiertes Design-Briefing für Designer

**Zeitaufwand:** 1-2 Stunden

---

## 📋 Checkliste

### Vor der Recherche

- [ ] Recherche-Script ausgeführt
- [ ] Suchbegriffe definiert
- [ ] Plattformen identifiziert
- [ ] Kandidaten-Liste vorbereitet

### Während der Recherche

- [ ] Jede Plattform durchsucht
- [ ] Kandidaten dokumentiert (Name, Link, Preis, Lizenz)
- [ ] Screenshots/Videos gespeichert
- [ ] Top 5 Kandidaten identifiziert

### Vor dem Interview

- [ ] Interview-Termin vereinbart
- [ ] Fragen vorbereitet (`docs/TEMPLATE_INTERVIEW.md`)
- [ ] Referenz-Templates angeschaut
- [ ] Protokoll-Vorlage erstellt

### Während des Interviews

- [ ] Alle Fragen gestellt
- [ ] Antworten dokumentiert
- [ ] Screenshots/Notizen gemacht
- [ ] Offene Fragen geklärt

### Nach dem Interview

- [ ] Protokoll erstellt (`docs/TEMPLATE_INTERVIEW_PROTOCOL.md`)
- [ ] Design-Briefing aktualisiert
- [ ] Moodboard erstellt
- [ ] Nächste Schritte definiert
