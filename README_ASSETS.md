# Professionelle Asset-Pipeline - Quick Start

## 🚀 Schnellstart

```bash
# 1. Professionelle Assets herunterladen
pnpm assets:professional

# 2. Assets aktivieren (in .env.local)
VITE_ECO_PROFESSIONAL=true

# 3. Dev-Server starten
pnpm dev:eco
```

## 📋 Was wird heruntergeladen?

- **HDRI**: 4K-Umgebungen von PolyHaven (Forest Slope, Spruit Sunrise, etc.)
- **Bäume**: Hochwertige Baum-Modelle (Oak, Pine, Birch)
- **Felsen**: Realistische Felsformationen
- **Vegetation**: Gras, Büsche, Blumen
- **Texturen**: Photorealistische Boden-Texturen

## 🎨 Qualität

Die Pipeline erstellt Assets in professioneller Qualität, ähnlich wie:

- **Arthur Metaverse**
- **RaveSpace Metaverse Nordwest**
- **Andere professionelle Metaverse-Plattformen**
