# Avatar Presets

Dieser Ordner enthält vorgefertigte Avatar-Modelle (GLB-Dateien).

## Erforderliche Dateien

- `capsule.glb` - Standard Capsule-Avatar (Dummy-Modell)

## Hinweis

Falls `capsule.glb` nicht vorhanden ist, wird ein Fallback verwendet.
Das Modell kann später durch ein echtes GLB ersetzt werden.

## Erstellen eines einfachen Capsule-Modells

Ein einfaches Capsule-Modell kann mit Blender oder einem anderen 3D-Tool erstellt werden:

- Einfache Kapsel-Form (Capsule-Primitive)
- Export als GLB
- Datei hier platzieren
